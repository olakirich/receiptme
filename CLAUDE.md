# receiptme

## Response format for this project

After any work on the site, reply in this structure and nothing else:

**Done** — 1–3 bullets, plain language. Name files only if I need to open them.
**Check** — one line: what to look at in the browser. Skip if nothing visual changed.
**Need from you** — numbered. Decisions, copy, assets. If nothing: "Nothing — continue?"

Rules:
- Under 120 words unless I ask for detail.
- No code in the reply. Code goes in the files.
- No preamble. Start with **Done**.
- If something broke or you skipped it, say that first, above **Done**.
- List anything you guessed at under "Assumed:" — one line each.
- Don't re-explain what we already agreed on.
